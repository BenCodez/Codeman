# Codex automatic input eligibility

Automatic recovery requires an isolated managed Codex pane and a complete current identity proof. Submit at least one ordinary prompt through Codeman in the current thread: the exact prompt and submission time must match its history, and the latest appended history entry must still name that thread.

A launch or resume seed alone remains available for an explicit owner launch or reboot plan. It does not authorize automatic continuation, restart, or task input. Without a tracked submission, automatic inspection reports `identity-unverified` and sends no input. Initial task kickoff therefore needs a tracked owner prompt in the exact thread first.

Switching threads directly inside the Codex TUI can leave Codeman's recorded submission unchanged. If current history names another thread or is incomplete, automatic input stops until a new exact owner submission establishes the current identity. Creation timestamps and attaching to a pane do not establish that authority.
